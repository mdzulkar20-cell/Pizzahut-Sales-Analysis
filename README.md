This repository contains a complete SQL-based analysis of Pizza Hut sales data, including KPIs, category insights, hourly order trends, revenue breakdowns, and advanced analytical queries.
All SQL queries used for the analysis are included in the file Pizza Hut Sales SQL Analysis.docx. 


📌 Project Objective

To analyze Pizza Hut's order, product, and revenue data to uncover insights related to:

* Total orders

* Revenue generation

* Pizza type & size performance

* Order patterns by date & time

* Category-level insights

* Customer demand trends

This analysis helps understand business performance and supports data-driven decision-making.

📁 Files Included

✔ Pizza Hut Sales SQL Analysis.docx

Contains all SQL queries for:

* Basic business KPIs

* Category analysis

* Time-based trends

* Revenue distribution

* Cumulative revenue

* Top/Bottom performing pizzas


✔ SQL-Pizzahut.sql

* A fully formatted .sql file for direct execution in SQL Server/MySQL.

📊 Key Insights from SQL Queries
🔹 1. Basic Metrics

* Total number of orders

* Total revenue

* Most expensive pizza

* Most common pizza size

* Top 5 ordered pizza types

🔹 2. Intermediate Insights

* Quantity ordered by pizza category

* Order distribution by hour

* Category-wise pizza variety

* Average pizzas ordered per day

* Top pizza types by revenue

🔹 3. Advanced Insights

* Revenue percentage by category

* Cumulative revenue over time

* Top 3 pizzas by revenue within each category

These queries provide a complete business analysis view of Pizza Hut's sales data.


🗄️ Database Tables Used

* pizzas

* pizza_types

* orders

* order_details

Each query joins these tables to produce meaningful insights into order behavior and pizza performance.

🛠️ Tech Stack

* SQL Server–Query execution

* SQL Joins, CTEs, Window Functions

* Aggregation & Date Functions
